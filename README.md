# Materials Informatics Lab

The group's website — <https://materials-informatics-az.github.io>.

Plain static HTML and CSS, generated by one Python script. 

## Editing the site

Everything you change day to day is in `content/`:

| File | What it holds |
|---|---|
| `site.yml` | Title, nav, feature flags, the recognition line |
| `people.yml` | The roster, the PI, fellowships, alumni |
| `papers.bib` | Publications — a normal BibTeX file, export over it from Zotero |
| `news.yml` | The news feed |
| `research.yml` | Research pillars and the landing hero figure |
| `tools.yml` | The group's web apps |
| `posts/` | Long-form posts, Markdown with front matter |

Whole sections of the site are one line: `features.research: false` in
`site.yml` removes the research page, its nav entry, and every link to it.
`notes/NOTES.md` has the full table of switches, along with image sizes, the
colour contrast measurements, and the go-live steps.

## Building

Needs **Python 3.10 or newer**. macOS ships 3.9 as `/usr/bin/python3`, so name
the version rather than using a bare `python3`:

```
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python build.py --serve      # http://localhost:8123
```

`build.py` reads `content/` through `templates/` and writes the finished site
into `_publish/`, copying `static/` in alongside it. That directory is exactly
what gets served — nothing else is published, and nothing published lives
anywhere else. It also checks every internal link and anchor, and prints
anything that does not resolve.

## Deploying

Pushing to `main` runs `.github/workflows/deploy-site.yml`, which builds, fails
on a broken internal link, and uploads `_publish/` to GitHub Pages. The source,
the templates and `notes/` are never in that directory, so they are never
served.

Repository settings → Pages → Source must be **GitHub Actions**.
`notes/deploy.md` is the full first-time setup.

## Layout

```
build.py            the whole build
content/            what you edit
templates/          Jinja templates
static/             CSS, JS, images — copied into the build as-is
_publish/           the built site; gitignored, rebuilt from scratch every run
```
